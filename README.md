# Слух — Arena Breakout: Infinite

Каждая крыса и каждый писк. Слух делает звук игры чётче: шаги, шорохи, перезарядку и бинты
слышно издалека, а выстрел рядом не бьёт по ушам. Работает в фоне — значок в трее рядом с
часами — и сам включается, когда запускаешь игру.

**🔑 Ключи доступа и новости — в Telegram-канале [@LorikoSant_Shop](https://t.me/LorikoSant_Shop).**

## Скачать

**[SluhSetup.exe — последняя версия](https://github.com/Lorik0Sant/Sluh-releases/releases/latest/download/SluhSetup.exe)**

1. Запусти `SluhSetup.exe` и нажми «Установить». Права администратора не нужны.
   Windows может показать «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в
   любом случае»: так она встречает любую программу без платной цифровой подписи.
2. При первом запуске введи ключ доступа `SLUH-XXXXX-XXXXX-XXXXX-XXXXX` — ключи выкладываются
   в Telegram-канале [@LorikoSant_Shop](https://t.me/LorikoSant_Shop).
   Один ключ — один компьютер; на своём компьютере ключ можно вводить снова (после
   переустановки Windows или Слуха). Если пишет «уже активирован на другом компьютере» —
   ключ забрали раньше тебя, возьми другой.
3. Всё. Слух запускается вместе с Windows и ждёт игру в трее.

Нужна Windows 11 или Windows 10 версии 2004 и новее.

## Как пользоваться

- **Запусти игру** — Слух сам её найдёт и включит обработку. Окно открывается щелчком по
  значку в трее; крестик прячет окно обратно в трей. Закрыть совсем — правой кнопкой по
  значку → «Выход».
- **Большая кнопка** или **Ctrl+Alt+F8** прямо в игре — включить/выключить обработку
  (удобно сравнить «до» и «после»).
- **Пресеты:**
  - **Крысы** — по умолчанию: вытягивает всё тихое — шаги, шорохи, перезарядку, бинты;
  - **Классика** — чистый звук: низ и гул убраны, щелчок шагов ярче, подтяжка мягкая;
  - **Максимум** — слышно всё, но ветер и дождь тоже громче: для тихих карт;
  - **Мягкий** — для долгих каток, уши не устают.
- **Подтяжка тихих** — насколько сильно тянуть тихие звуки; **Громкость** — общая громкость в
  наушниках; **Потолок громкости** — выше него не поднимется ничего, даже выстрел над ухом.
- **Стрим и Discord.** Слух меняет только то, что слышишь ты. Если в компьютере есть
  «запасной» выход звука (цифровой S/PDIF, выход на монитор по HDMI/DisplayPort и т. п.),
  OBS с захватом звука игры слышит её как обычно. Если запасного выхода нет — Слух скажет об
  этом в окне.
- **Обновления** приходят сами: в окне появится зелёная полоса «Вышла новая версия» → «Обновить».
  Настройки и ключ сохраняются.
- **Удалить** — «Параметры Windows» → «Приложения» → «Слух» → «Удалить». Громкость и
  устройство игры Слух вернёт как было.

## Античит

Слух не трогает игру: не открывает её процесс, не читает память, ничего не внедряет и не
нажимает за тебя кнопки. Звук берётся штатным механизмом Windows — тем же, что у OBS для
захвата звука приложения. При этом правила игры формально могут запрещать сторонние
программы, дающие преимущество, — решай сам.
